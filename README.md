## 100M 独享为什么下载跑不到 12.5MB/s

独享带宽指服务商在虚拟化层或交换机端口上，给你划一段固定专用的吞吐管道。同物理机的其他租户跑满，你的配额也不被挤占，这就是它和共享带宽（一池子几十上百台共用 1Gbps，靠“非全员同时满载”的概率撑着）的根本区别。共享池里只要几台机器持续大流量下载或挨了 DDoS，其余用户就会遭遇邻居效应，晚高峰吞吐陡降、丢包上升。

但独享保障的是服务端这段通道的确定性，不是整条链路。100Mbps ÷ 8 = 12.5MB/s 只是理论值，实际卡在四个地方：

- 你本地的宽带、Wi-Fi 信号或运营商限速；
- 跨境 RTT 延迟，TCP 窗口涨不上去，单线程填不满带宽；
- 对端服务器的 CPU、磁盘 I/O、Nginx 并发连接池；
- 国际出口和运营商互联节点在晚高峰的丢包。

所以看到“100M 独享”先别换算成 12.5MB/s，它保证的是你这一端不会被人抢，不保证对端和中间链路不出问题。

## 线路决定体验：CN2 GIA、CMIN2、BGP 各适合谁

带宽数字不等于体验。同样 100Mbps，走普通国际线路和走 CN2 GIA，晚高峰是两个世界。

- **电信 CN2 GIA（AS4809）**：双向直连，高峰期丢包低，是目前对大陆访问质量最好的商业线路之一。CN2 还分 GT 和 GIA 两级，GIA 更高级、更贵。
- **联通 AS9929 / 移动 CMIN2**：各自的优质通道，移动用户尤其要看 CMIN2。
- **BGP 多线直连**：按访客运营商自动选路，降低跨网延迟。

有独立路由测试显示，LightLayer 的回程走电信 CN2 GIA 和移动 CMIN2，31 个省份到电信的平均延迟 157.9ms。这个数字放在洛杉矶机房里算正常偏好。回头看它的 Premium 档，端口只有 20–50Mbps 却比 Global 档的 200Mbps 更贵，差的就是这条回程线路。10M 优质线路胜过 100M 普通线路，这句话在这里有具体价格作证。
